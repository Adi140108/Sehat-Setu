# Sehat Setu — Privacy & Data Minimization Policy

## Core Privacy Directives

1. **Data Minimization**:
   - Sehat Setu collects only the absolute minimum parameters required to locate healthcare facilities and evaluate preliminary scheme rules (e.g. age, state, pincode).
   - Sensitive medical diagnosis or personal health records are **never** requested or stored.

2. **No Raw Voice Retention**:
   - Audio inputs captured via the Web Speech API are transcribed in memory to text and immediately discarded. No permanent audio recording files are saved.

3. **Anonymized Analytics**:
   - The public administration dashboard exposes strictly anonymized, aggregated intent counts and language usage distributions. No personally identifiable information (PII) is included in analytics data.

4. **Right to be Forgotten ("Delete My Data")**:
   - Every citizen user can purge their local profile session and household data instantly by clicking **"Delete My Data"** in the UI.
